# NOIR X1 Launch Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (user pre-authorised native execution without per-document review). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the NOIR X1 launch experience described in the spec: real GLB watch, scroll-choreographed scenes, materials, explore mode, collection, story, finale.

**Architecture:** One persistent R3F canvas fixed behind semantic DOM sections. DOM anchors (`data-pose`) are converted by `poseTrack` into an interpolated pose singleton that `CameraRig` damps toward each frame. zustand holds discrete UI state (material, variant, mode, quality, hotspot).

**Tech Stack:** Vite 8, React 19, TypeScript, three 0.186, @react-three/fiber 9, @react-three/drei 10, gsap 3.15 + ScrollTrigger, lenis 1.3, zustand 5, Playwright 1.63, @gltf-transform/cli.

**Spec:** `docs/superpowers/specs/2026-09-27-noir-x1-design.md`

## Global Constraints

- Site copy in English; every spec labelled as a concept specification; no invented prices, retailers, press or testimonials.
- Colours only from tokens: graphite `#0C0C0D`, bone `#ECE8E1`, 11-step neutral ramp, signal `#FF5A1F` (seconds hand + live measurement marks only).
- Fonts: Archivo variable (wdth + wght) and Geist Mono (measurements only). Self-hosted via @fontsource-variable.
- No kicker or eyebrow labels above headings; no card grids; no gradient text; no decorative glass.
- Named GLB nodes and materials exactly as in spec §3.1.
- No third-party models, photos or HDRIs.
- Every animation must respect `prefers-reduced-motion`.
- Hover effects gated behind `(hover: hover) and (pointer: fine)`.

## Review Focus

1. **WebGL unavailable or context lost:** the page must still show pose-matched stills and all copy. The test forces the no-WebGL path via `?nowebgl`.
2. **Window resize or orientation change mid-scroll:** anchors must re-measure and the pose must not jump to a wrong scene. Test: resize, then assert the rail's active scene is unchanged.
3. **Explore opened then Escape, or opened from a mid-page scroll:** scroll position and Lenis state must be restored. Test: record `scrollY`, open, press Escape, and assert the same `scrollY`.
4. **Keyboard-only visitor:** they must reach every CTA, material radio, rail item and hotspot, with visible focus. Test: tab sequence covers the material radios, and pressing Enter on the Explore CTA opens the dialog.
5. **Reduced motion:** no scroll-scrubbed camera; content is visible without animations. Test: emulate reduced motion, scroll to engineering, and assert the headings are visible (opacity 1).
